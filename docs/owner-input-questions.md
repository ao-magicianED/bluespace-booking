### A-3. 鍵が開かないときの緊急手配先(⚠️ 唯一の未決定)

現状は「その都度探す」とのことでした。無人運営でいちばん重いのは「**利用開始時刻に入れず、連絡もつかない**」状態で、返金だけでは収まらずSNSに書かれる典型パターンです。**下記から1つ選ぶだけ**で埋まります(詳細は`complaint-response-readiness.md` 5-4)。

**Q5. 夜間・移動中など、自分がすぐ現地に行けないときの入室手段をどうしますか?**
- (a) **24時間対応の鍵業者を1社決めて番号を控える** … 使わなければ費用ゼロ。呼ぶと1回1万〜2万円が相場
- (b) **近隣の協力者に予備キーの保管と駆けつけを頼む** … 安いが、確実に繋がるかは人による
- (c) **予備の入室手段を各拠点に用意する**(番号を分けた予備キーボックス等) … 初期費用のみ。駆けつけ自体が不要になる ← **無人運営との相性は一番よい**
- (d) 今のまま(その都度探す)で進める … リスクを承知の上で、という記録だけ残します

**Q6.(Q5で(c)を選んだ場合)予備の番号を伝えたあと、番号を変更する運用にできますか?**
- (a) できる(利用後に自分で変更する)
- (b) 難しい → 別の方法を一緒に考えます

### A-4. 鍵まわりで、事故を減らすために決めておきたいこと

**Q7. テンキー錠の電池は、どのタイミングで交換していますか?**
- (a) 定期的に交換している(例: 半年ごと) → 頻度を教えてください
- (b) 切れてから交換している
- (c) 交換したことがない・分からない

> なぜ聞くか: 「入れない」の連絡で一番多いのが電池切れです。清掃時にまとめて交換する運用にすると、夜間の駆けつけがほぼ無くなります。

**Q8. 暗証番号は、利用ごとに変更していますか?**
- (a) 利用ごと(または頻繁に)変更している
- (b) 固定のまま
- (c) 拠点によって違う

> なぜ聞くか: (b)の場合、過去の利用者がいつでも入室できる状態です。盗難や鉢合わせが起きたとき、**保険は「自社に過失がないケース」しか対象にならない**ため、管理責任を問われると補償の外に出ます。ここは費用ゼロで潰せるリスクです。

**Q9. 防犯カメラのメーカー/機種と、サポート窓口は分かりますか?**
- (a) 分かる → メーカー名・機種を教えてください
- (b) 分からない(アプリ名だけ分かる等)
- (c) カメラが無い拠点がある → どの拠点か教えてください

> なぜ聞くか: クレーム対応の事実確認は「防犯カメラ映像+入退室記録」が根拠になります。映像が見られない拠点があるなら、その拠点だけ別の確認手段(清掃記録・前後の予約)に頼る前提で手順を書き分けます。

## B. 運営代行の月額(公開は止めていません)

`/consulting`の3メニューのうち、**運営代行の月額だけが未確定**です。市場に比較対象がなく(`competitor-creator-research.md`)、他社価格から逆算できないため、**自分の工数から積む**しかありません。下の4問で出せます。

**Q10. 1拠点を1ヶ月まわすのに、実際どれくらい時間を使っていますか?**(ざっくりで構いません)
- 清掃手配・立ち会い: 　　時間/月
- 問い合わせ・予約対応: 　　時間/月
- 売上集計・モール更新: 　　時間/月
- 写真差し替え・掲載文の改善: 　　時間/月
- トラブル対応(平均): 　　時間/月

**Q11. 自分の時間を1時間あたりいくらとして計算したいですか?**
- (a) 3,000円 (b) 5,000円 (c) 8,000円 (d) 10,000円以上 (e) 決めていない

**Q12. 運営代行は、同時に何拠点まで受けられますか?**
- (a) 〜3拠点 (b) 〜5拠点 (c) 〜10拠点 (d) 分からない

> なぜ聞くか: 「月間新規3件まで」と同じで、**受けられる上限を先に決めておかないと、埋まった瞬間に品質が落ちます。** 上限は`/consulting`にそのまま正直に書けます(嘘のない希少性は使えます)。

**Q13. 料金の形はどれにしますか?**
- (a) 固定の月額のみ
- (b) 固定の月額 + 売上に対する成果報酬(例: 増加分の◯%)
- (c) 売上に対する成果報酬のみ
- (d) 決めていない

> 補足: (b)(c)は「売上が増えなければ費用が抑えられる」ため相手には魅力的ですが、**増加分の定義**(何と比べた増加か、季節変動をどう扱うか)を契約書に書いておかないと、後で必ずもめます。選ばれた場合は定義案も一緒に作ります。

## C. 実績「100万円以上UP」の裏取り(公開は止めていません)

掲載同意は取得済み・物件名やオーナー名は不掲載、という条件も確認済みです。残るは**根拠資料**だけ。手順書は`case-study-evidence-kit.md`にあり、支援先に送るメール文面もそこに用意してあります。

**Q14. 支援先に、下記のデータ提供をお願いできそうですか?**(支援開始前3ヶ月・支援後3ヶ月の月次売上または予約件数。モールの管理画面のスクショで可)
- (a) 頼める → `case-study-evidence-kit.md` 3章のメール文面をそのまま送ってください
- (b) 頼みにくい → その場合は「100万円」という数値を使わず、定性的な表現に留めます
- (c) 自分の手元にもうデータがある → そのまま保管フォルダにまとめてください

**Q15. その「100万円」は、どちらですか?**
- 期間: (a) 月商 (b) 年間累計 (c) 分からない
- 種類: (a) 売上(総額) (b) 粗利 (c) 分からない

> なぜ聞くか: 消費者庁から根拠資料を求められた場合、**原則15日以内**に出す義務があります(不実証広告規制)。定義が曖昧なまま出すと、資料があっても「その数値の裏付けになっていない」と判断されます。逆に、定義が固まって資料が揃えば堂々と使えます。
