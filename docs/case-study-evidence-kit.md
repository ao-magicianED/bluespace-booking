# 実績事例の裏取りキット(「売上100万円以上UP」を使えるようにするための実務手順)

作成: 2026-09-03 / 対象: 外部コンサル支援先の実績事例
関連: `docs/media-disclosure-strategy.md` 10章・付録C#6

## 0. このキットの目的

「支援先の売上が100万円以上アップした」という実績を、note・YouTube・`/consulting`で**数字として使えるようにする**ための手順書。現在この数値は使用を止めており(付録C#6)、解除の条件がこのキットを一通り終えることになる。

**現在のステータス**

| 項目 | 状態 |
|---|---|
| 支援先の掲載同意 | ✅ 取得済み(2026-09-01確認)。条件: 具体的な物件名・オーナー個人が特定される情報は不掲載 |
| 根拠資料(契約書・売上台帳・Before/After) | ❌ 未整備 ← **これが最後の1つ** |
| 「100万円」の定義 | ❌ 未確定(月商か年間か、売上か粗利か) |

## 1. なぜ「後から集める」ではダメなのか

景品表示法には**不実証広告規制**(第7条第2項)がある。効果・実績を謳う表示について消費者庁から資料提出を求められた場合、**原則15日以内**に合理的根拠を示す資料を提出しなければならず、出せない場合はその表示が不当表示(優良誤認)とみなされる。

15日というのは、「支援先に連絡してデータをもらって整理する」には短すぎる。**公開を始める前に、手元に揃っている状態にしておく必要がある。** 逆に言えば、揃ってしまえば堂々と使える。

## 2. 集めるもの(チェックリスト)

- [ ] **①支援前後の売上データ** — 支援開始前と支援後の、月次の売上または予約数がわかるもの。支援先からの提供が必要。スクリーンショット可(モールの管理画面等)。**最低でも支援前3ヶ月・支援後3ヶ月**あると「一時的な変動ではない」と示しやすい
- [ ] **②「100万円」の定義の確定** — 下記3点を支援先と一緒に確認する
  - 月商か、年間累計か
  - 売上(総額)か、粗利か
  - 支援先の投資額(内装費・広告費等)を差し引く前か、後か
- [ ] **③支援の事実がわかるもの** — 契約書、または業務委託の合意がわかるメール/チャット。「いつからいつまで」「何を支援したか」が読み取れること
- [ ] **④実施した施策の記録** — 写真差し替え・価格改定・掲載媒体追加など。**実施日がわかる形**が望ましい(施策の前後関係を示せるため)
- [ ] **⑤外部要因の確認** — 同時期に季節要因・近隣の競合撤退・市場全体の需要増などが無かったか。あった場合は「施策以外の要因も寄与した可能性」として記録しておく(隠すとむしろリスク)
- [ ] **⑥同意ログの保管** — 取得済みの「事例として紹介してよい」という同意(メール/チャット)を、後から出せる場所に保存する
- [ ] **⑦保管場所の確定** — ①〜⑥を1つのフォルダにまとめる(例: Google Drive「コンサル実績_裏取り」)。**15日以内に出せる状態**であることが要件なので、探さないと出てこない状態は不可

## 3. 支援先への依頼文テンプレート

同意は既に取得済みなので、これは**データ提供のお願い**。そのまま使えるよう文面を用意した(送信前に必ず内容を確認・調整すること)。

```
件名: 事例紹介にあたっての数値確認のお願い

〇〇様

いつもお世話になっております。ブルーステージ合同会社の菅野です。

先日ご快諾いただいた事例紹介の件で、1点お願いがございます。

弊社では、支援実績を紹介する際に「売上が◯◯万円改善した」といった
数値をお伝えする場合、その根拠となる資料をあらかじめ手元に保管して
おく必要があります(景品表示法上、根拠資料の提出を求められた際に
15日以内に対応する義務があるためです)。

つきましては、差し支えのない範囲で下記をご提供いただけますでしょうか。

1. 支援開始前3ヶ月と、支援後3ヶ月の月次の売上または予約件数
   (モールの管理画面のスクリーンショットで構いません)
2. 「売上が伸びた」とお感じの数字が、月商・年間累計のどちらか
3. その数字が、経費を差し引く前か後か

いただいた資料は弊社内での保管のみに使用し、公開はいたしません。
また、以前お伝えしたとおり、公開する記事・動画では
**物件名やお名前など、〇〇様が特定される情報は一切掲載いたしません。**
掲載するのは「支援先の売上が改善した事例がある」という範囲に留めます。

ご負担をおかけしますが、ご確認いただけますと幸いです。

ブルーステージ合同会社
菅野雄策
```

## 4. 揃ったら何ができるようになるか

資料が揃った時点で、`docs/media-disclosure-strategy.md` 10章の打消し表示パターンに沿って、以下が使えるようになる。

| 使えるようになる表現 | 必須の打消し表示 |
|---|---|
| note記事末尾: 「支援後に月間の予約・売上が大きく伸び、**100万円以上の増加**につながったケースがあります」 | 「※上記は個別の事例であり、立地・投資額・競合状況・実施した施策等の条件によって結果は異なります。同様の成果を保証するものではありません」を**同じ文字サイズで隣接**させる |
| YouTube: 口頭で言及 | 該当カットの間ずっと、本文と同サイズのテロップで打消し表示を出し続ける(ワンカットで消さない) |
| `/consulting`ページ | 現在の一般的表現を、数値入りに差し替え可能 |

**引き続き禁止**: 「必ず」「誰でも」等の保証表現、物件名・オーナー名の掲載、複数事例を平均値のように語ること(1件なら1件と書く)。
